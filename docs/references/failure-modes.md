# Failure modes

One table per module, added as each one is converted. Each row is Inference, from reading the code on 2026-11-11, unless it says otherwise. Linking each row to its test, or to its reason in `test/real-only.txt`, comes with the harness split in issue 4.

## The helper

`libexec/pam-duo-macos-updater-root` swaps in a verified module as root. Its exit codes are in [Exit codes](exit-codes.md). Every failure before the swap refuses, and every failure after it restores.

| Step                       | Failure                                                                              | What happens                                                                                                                                                                                             |                             Exit |
| :------------------------- | :----------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------: |
| Arguments                  | Not three, a checksum that isn't 64 hex characters, or an empty or unexpected run ID | Prints the usage                                                                                                                                                                                         |                              `2` |
| Root check                 | Not running as root                                                                  | Prints why                                                                                                                                                                                               |                              `2` |
| Lock                       | `touch` fails on the lock file                                                       | Stops                                                                                                                                                                                                    |                              `2` |
| Lock                       | Another install holds the lock                                                       | Prints to try again in 3 minutes                                                                                                                                                                         |                              `2` |
| Duo config                 | Not `root:wheel` mode 600, or `stat` fails                                           | Prints why                                                                                                                                                                                               |                              `2` |
| Duo config                 | No `failmode = secure` line, or more than one `failmode` line                        | Prints why                                                                                                                                                                                               |                              `2` |
| OpenSSL folder             | Exists and isn't owned by root with mode 755                                         | Prints why                                                                                                                                                                                               |                              `2` |
| PAM config                 | No uncommented line names the module, or the file is missing                         | Prints that Duo isn't turned on                                                                                                                                                                          |                              `2` |
| Installed module           | Missing                                                                              | Prints to see the playbook                                                                                                                                                                               |                              `2` |
| Leftover swapped marker    | An earlier install never finished                                                    | Restores the last proven module first, then carries on                                                                                                                                                   |                                — |
| Leftover swapped marker    | That restore fails                                                                   | Prints `RESTORE FAILED` and keeps the marker                                                                                                                                                             |                              `5` |
| Staging copy               | `install` fails                                                                      | Stops before anything live changes                                                                                                                                                                       |                              `2` |
| Staging copy               | Its checksum doesn't match, or `shasum` fails                                        | Removes the copy and prints that the module changed                                                                                                                                                      |                              `2` |
| Keeping the working module | `cp -p` fails                                                                        | Stops before anything live changes                                                                                                                                                                       |                              `2` |
| Pending marker             | Can't be written                                                                     | Stops before anything live changes                                                                                                                                                                       |                              `2` |
| Swap                       | `mv` fails                                                                           | Clears the trap and the marker, and prints why                                                                                                                                                           |                              `2` |
| Waiting for proof          | A hangup, interrupt or terminate signal                                              | Restores the last proven module                                                                                                                                                                          |                              `4` |
| Waiting for proof          | No approval within 180 seconds                                                       | Restores the last proven module                                                                                                                                                                          |                              `3` |
| Restore                    | `cp -p` or `mv` fails                                                                | Prints `RESTORE FAILED` and keeps the swapped marker, so the daily check alerts                                                                                                                          |                              `5` |
| Writing the run ID         | Fails after the swap                                                                 | Ignores signals, prints why and restores the last proven module, as the proof could never start. The script reports this exit as no Duo approval arriving, so the reason is only in the helper\'s output | `3`, or `5` if the restore fails |
